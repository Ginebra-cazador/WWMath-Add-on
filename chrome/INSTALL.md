# Chrome installation (v2.3.15)

1. Extract the ZIP to a permanent folder.
2. Open `chrome://extensions`.
3. Enable **Developer mode**.
4. Select **Load unpacked** and choose the extracted folder.
5. Open Where Winds Math.
6. Select **Enable WWM Patch** at the lower-right of the page.
7. Accept Chrome's debugging notice and allow the automatic reload.

When the button reads **WWM Patch: ON**, selecting it opens the configuration editor. Save changes and reload the calculator.

In Settings > Player Level choose the website's native **Lv.100** to preserve its data or **Lv.100 (Fixed)** for the confirmed 6% `(attune)` maximum and updated Stonesplit coefficients. The editor separates player/enemy levels, tuning, coefficients, and gear into four JSON sections.

Chrome displays its standard debugging banner while live response interception is active. Closing the tab ends that session; select **Enable WWM Patch** again in a new calculator tab.
